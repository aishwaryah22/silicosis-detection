# silicosis-detector  —  rises.AI Silicosis Diagnostic Service

DenseNet-121 · ILO Profusion Scoring · PMF Detection · Grad-CAM

---

## Before you build Docker — run this once

```bash
# 1. Place your trained weights in models/
cp best_silicosis_model.pth  models/best_silicosis_model.pth

# 2. Install deps
pip install torch torchvision onnxruntime pyyaml

# 3. Export ONNX from your .pth
python pipeline/convert_to_onnx.py
# → creates models/silicosis_model.onnx
```

---

## Docker — build & run

```bash
docker build -t silicosis-service .
docker run -p 8000:8000 silicosis-service
```

Server is ready on **http://localhost:8000** in ~10 seconds.

---

## Test the API

```bash
# Health check
curl http://localhost:8000/

# Predict on a chest X-ray
curl -X POST http://localhost:8000/predict \
     -F "file=@data/normal_001.jpg" | python -m json.tool
```

## Project structure

```
silicosis-detector/
├── models/
│   ├── best_silicosis_model.pth   ← your trained PyTorch weights
│   └── silicosis_model.onnx       ← generated by convert_to_onnx.py
├── src/
│   ├── api.py          FastAPI server
│   ├── model_def.py    SilicosisNet class (single source of truth)
│   ├── inference.py    ONNX runtime engine
│   ├── preprocessor.py Image resize + normalise
│   ├── segmentor.py    Lung ROI extraction
│   ├── gradcam.py      Grad-CAM on denseblock4.denselayer16.conv2
│   └── report.py       Clinical report text generator
├── pipeline/
│   └── convert_to_onnx.py   .pth → silicosis_model.onnx
├── data/               ≥5 normal + ≥5 abnormal sample X-rays
├── config.yaml         All settings — zero hardcoded paths in code
├── Dockerfile
├── .dockerignore
├── requirements.txt
└── README.md
```

## ILO Profusion Scale

| Index | Class | Severity |
|-------|-------|----------|
| 0 | 0/- | Sub-threshold |
| 1 | 0/0 | Normal |
| 2–3 | 0/1, 1/0 | Borderline |
| 4–5 | 1/1, 1/2 | Mild |
| 6–8 | 2/1 – 2/3 | Moderate |
| 9–11 | 3/2 – 3/+ | Severe |
